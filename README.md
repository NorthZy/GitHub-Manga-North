## Ep.6 The-soul-that-is-extinguished


มิติสุดท้ายกำลังแตกเป็นเสี่ยง
“ความเป็นจริง” และ “ความน่าจะเป็น” บิดเบี้ยวจนแทบไม่เหลืออะไรเหมือนเดิมอีกต่อไป
น้องจิ้งจอกยืนอยู่กลางสมรภูมิที่เต็มไปด้วย “ตัวตนของตัวเองจากทุกโลก” — บางคนเป็นนักรบ บางคนเป็นฆาตกร บางคนแค่น้ำตาไหลเงียบ ๆ

แต่ทั้งหมดมีจุดร่วมเดียวกัน: พวกเขารักบอส

“พวกเรา... คือความเป็นไปได้ทั้งหมดของนาย”
“แต่มีเพียงหนึ่งเดียวเท่านั้น ที่จะได้รักษา ‘บอส’ ไว้”

“เลือกซะ... ว่าความจริงของนายควรจะจบแบบไหน”
เสียงจากมิติเวลาภายในดังขึ้น — เสียงที่ให้พลังเขามาแต่แรก
น้องๆที่ให้พลังเขานั่นเอง

แล้วเขาก็ตัดสินใจ
เขาใช้พลังทั้งหมด ยุบรวมตัวตนทุกโลกเข้าด้วยกันเป็นหนึ่งเดียว
— เพื่อสร้าง “โลกใหม่” ที่ไม่มีอดีต ไม่มีบาป ไม่มีการแก้แค้น
แต่มีเพียง “โอกาสครั้งใหม่” ให้บอสได้มีชีวิต และให้เขา... ได้เริ่มต้นใหม่อีกครั้ง แม้ตัวเขาจะหายไปตลอดกาล

สุดท้าย... มิติใหม่ถือกำเนิดขึ้น

ในร้านอาหารเล็ก ๆ แห่งหนึ่ง
ชายคนหนึ่งกำลังล้างจานอยู่หลังเคาน์เตอร์
เสียงหัวเราะดังมาจากโต๊ะลูกค้าคนหนึ่ง — บอส หนุ่มอ่อนโยนในโลกนี้ มีชีวิตที่เรียบง่าย

ไม่มีแก๊ง ไม่มีความตาย ไม่มีจิ้งจอก...

แต่หากคุณสังเกตดี ๆ
จะเห็นเงาเล็ก ๆ บนกระจกใสบานหนึ่ง — เงาของชายผู้มีดวงตาสีเงินเรืองแสง
ที่ยิ้ม... แล้วหายไป

“นี่ไม่ใช่โลกที่ฉันอยู่… แต่เป็นโลกที่ฉันยอมตายเพื่อสร้าง”
— เสียงสุดท้ายของน้องจิ้งจอก, ก่อนจิตจะดับสูญ
