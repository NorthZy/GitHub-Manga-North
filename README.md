## Ep.5 The-Sin-you-have-been-holding


ไฟสีเงินลุกวาบจากฝ่ามือของน้องจิ้งจอก แสงจาก “พลังแห่งโลกคู่ขนาน” เผยให้เห็นรอยแผลเป็นบนหัวใจของเขา — ความเสียใจ ความโกรธ และคำถามนับพันที่ไม่เคยได้คำตอบ

ฉึบ—!
เขาฉีกม่านกั้นมิติ เปิดประตูสู่โลกคู่ขนานที่เต็มไปด้วยความเป็นไปได้ เขากระโจนผ่านเส้นกาลเวลา สัมผัสความจริงมากมายในพริบตา

โลกที่ 1 — แก๊งนั้นไม่เคยเกิดขึ้น
ในโลกนี้ “บอส” ยังมีชีวิต มีครอบครัว มีความสุข แต่น้องจิ้งจอกในโลกนี้... ไม่มีตัวตนเลย

“ถ้าโลกนี้ไม่มีฉัน... บอสถึงได้ปลอดภัยงั้นเหรอ?”

โลกที่ 2 — บอสเป็นหัวหน้าแก๊งเสียเอง
ที่นี่บอสกลายเป็นผู้ล่า ไม่ใช่เหยื่อ ใบหน้าอันอบอุ่นที่เคยจำได้ บัดนี้เย็นชาไร้ความปรานี

“ความดีมันไม่มีที่ยืนในบางโลก… หรือว่านั่นคือความจริงทั้งหมด?”

โลกที่ 3 — น้องจิ้งจอกกลายเป็นศัตรูตัวฉกาจของบอส
เขาเผชิญหน้ากับตัวเองที่เลือดเย็นจนแม้แต่ตัวเขายังหวาดกลัว

“ฉัน... มีศักยภาพจะเลวได้ขนาดนี้เลยเหรอ?”

ทุกก้าวที่ผ่าน เขาสะสม “บาป” จากทุกโลกที่แวะเวียน ไม่ใช่เพื่อสู้ แต่เพื่อเข้าใจ
และในที่สุด เขามาถึงโลกที่บอส... กำลังจะถูกฆ่าอีกครั้ง เหมือนในโลกต้นฉบับ

แต่ครั้งนี้เขาไม่ใช่เหยื่อ
ครั้งนี้... เขามี “พลังของทุกตัวตน” อยู่ในมือ

“จงจำไว้... บอสของฉัน ต้องมีชีวิตอยู่ในโลกนี้ — ไม่ว่าฉันจะต้องสลายไปกี่ร่างก็ตาม!”
